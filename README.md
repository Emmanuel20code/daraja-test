# Daraja STK Push Test

This project demonstrates a Node.js Express server that integrates with the Safaricom Daraja Production API.

## Features

- OAuth Access Token
- STK Push
- Callback Endpoint

## Environment Variables

Create the following variables in Render:

- CONSUMER_KEY
- CONSUMER_SECRET
- SHORTCODE
- PASSKEY
- PHONE
- CALLBACK_URL
- PORT
